# CalculaFácil



**Ferramentas gratuitas para facilitar sua vida.**



**Acesse o portal:** [CalculaFácil](https://pedroicsan.github.io/calculafacil/)



Portal estático em português brasileiro com 15 calculadoras gratuitas. Os cálculos são feitos no navegador, sem login, servidor, banco de dados, IA ou APIs pagas. Após o primeiro carregamento, as páginas podem funcionar offline se o navegador mantiver o cache local.



O projeto é publicado gratuitamente pelo GitHub Pages a partir deste [repositório público](https://github.com/pedroicsan/calculafacil). O workflow do GitHub Actions executa os testes e gera o site antes de cada publicação.



**Pacote completo de fontes, testes e instruções:** [`CalculaFacil-portal-fonte.zip`](./CalculaFacil-portal-fonte.zip)



Para compilar localmente, extraia o ZIP, entre na pasta `calculafacil` e execute `python3 scripts/build_site.py`. O gerador usa apenas a biblioteca padrão do Python.
